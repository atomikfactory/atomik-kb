# atomik-kb user guide

atomik-kb is a private notes and knowledge-base app. Your pages are stored encrypted on
your own computer, and you decide whether they sync anywhere.

| Chapter | Read it to |
|---|---|
| [Getting started](getting-started.md) | Install the app, create a workspace, save your recovery kit |
| [Writing and organizing](writing-and-organizing.md) | Pages, blocks, spaces, tabs, favourites, templates, trash, search, history |
| [Databases](databases.md) | Properties, views, filters, formulas, dashboards, relations |
| [Sync and devices](sync-and-devices.md) | Run a sync server, connect and pair devices |
| [Sharing](sharing.md) | Shared spaces, roles, invitations and view-only links |
| [Backup and restore](backup-and-restore.md) | Backup files, scheduled and Google Drive backups, restoring |
| [Import and export](import-export.md) | Bring notes in from other apps, take them out |
| [AI and dictation](ai-and-dictation.md) | Optional local AI, the MCP server and speech-to-text |
| [Privacy and security](privacy-and-security.md) | What is protected, from whom, and the limits |
| [Troubleshooting](troubleshooting.md) | Common problems and fixes |

Menu names in this guide are written as they appear in the app, for example
**Settings > Security**. The app is available in English, French and Spanish
(**Settings > Appearance > Language**); this guide uses the English labels.
